# COO Dashboards

Репозиторій для COO-дашбордів, опублікованих через GitHub Pages.

## Структура

Кожен дашборд зберігається в окремій папці:

```text
dashboards/
  dashboard-name/
    index.html
    ...
```

Після публікації адреса дашборду матиме вигляд:

```text
https://hryhoriihaponiukquitcode.github.io/COO/dashboards/dashboard-name/
```

Коренева сторінка репозиторію:

```text
https://hryhoriihaponiukquitcode.github.io/COO/
```
